  1. Open Claude → Settings → Connectors
  2. Click Add Remote MCP Server
  3. Paste your MeetingPilot MCP URL
  4. Enable tools & prompt Claude!

Run this command in terminal:

claude mcp add --transport http meetingpilot <URL>

In claude_desktop_config.json:

{
  "mcpServers": {
    "meetingpilot": {
      "type": "http",
      "url": "..."
    }
  }
}
